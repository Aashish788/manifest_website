🧪 Quick Deep Link Test

Test if your app's deep linking is configured correctly

📋 What this tests:

Direct Deep Link:
Tries to open: manifestation://reel/test123
✅ Should open your app directly
❌ If nothing happens, check AndroidManifest.xml / Info.plist

Web Redirect:
Opens: manifestdream.site/reel/test123
✅ Should show redirect page, then open app
❌ If stuck on redirect page, check app configuration

💡 Pro Tips:
• Make sure your app is installed
• Check that scheme is "manifestation" in app
• Look at browser console (F12) for errors
• Try different video IDs to test
